# 这些定义会被dcon编译器生成对应的C++代码，用于游戏运行时数据访问。

# 主要关键字说明：
# - make_index: 定义索引类型，用于快速查找对象
# - object: 定义数据对象，类似于数据库表
# - relationship: 定义对象之间的关系，类似于数据库外键
# - property: 定义对象的属性/字段
# - tag: 标记属性，用于控制数据加载和保存行为
#   - scenario: 仅在场景初始化时加载的数据
#   - save: 需要保存到存档的数据
#   - local_save: 本地保存的数据（多人游戏时不参与校验和）
#   - mp_data: 多人游戏数据
#   - mp_checksum_excluded: 排除在多人游戏校验和计算之外的数据
#   - keep_after_state_reload: 状态重载后保留的数据
# ============================================================================
